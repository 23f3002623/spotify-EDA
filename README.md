# 🎵 Spotify Global Music Analysis Project

## 🔍 Project Overview

This data analysis project explores **Spotify's global music trends** using Python, pandas, seaborn, and matplotlib.  
The main goal is to understand how musical preferences, popularity, and streaming behavior vary across artists, genres, and countries.

## 📊 Objectives

- Discover what features influence a song’s popularity
- Identify top global artists and songs
- Analyze genre trends over the years
- Examine emotional factors (valence, danceability, tempo)
- Seasonal song release patterns
- Country-wise streaming behavior and genre preference
- Compare happy vs sad songs in popularity

## 📁 Technologies Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## 📂 Dataset

- `Spotify_Dataset_V3.csv`
- Source: Kaggle & Spotify API-based datasets
